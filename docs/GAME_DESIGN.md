# Best 11 — Game Design

## Product pillars
1. Read space: tactical shape and off-ball movement communicate options.
2. Control the ball: deliberate first touch, passing power, shot selection and skill gestures.
3. Exploit width: wingers stretch defensive shape and create through-ball lanes.
4. Manage the legs: sprinting trades short-term speed for late-match fatigue.
5. Build the club: offline career progression, recruitment and facility upgrades.

## Match feel
Fast-paced arcade simulation with slightly weighty movement. Core match play must remain available offline. Online is reserved for PvP, events, leaderboards and optional cloud sync.

## Fictional content
Use procedurally generated club, player, country and tournament identities. Do not bundle real player names, official crests, licensed kits, broadcast audio or recognizable likenesses.

# Content and licensing policy

This repository intentionally abandons third-party licensing integrations and contains no real player names, real club identities, official badges, licensed kits, FIFPRO data, or recognizable real-person likenesses. Starter squads are fictional. Use original assets or content for which the project owner has explicit rights. URL import tools should validate file type, size and user rights; importing a URL does not grant permission to use its contents.

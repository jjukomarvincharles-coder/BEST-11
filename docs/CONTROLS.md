# Controls

Planned touch layout: fixed or floating 360-degree stick; PASS, THROUGH, SHOOT, PRESS, SWITCH and SLIDE action buttons. Holding PASS/THROUGH/SHOOT charges power. Shot swipes add finesse and curve. Manual goalkeeper rush is available in one-on-ones.

Gamepad support should route Bluetooth/USB controller input through a normalized action map and hide touch controls while a controller is active.

Prototype desktop controls: WASD/arrows move, Shift sprints, Space/J performs a basic ball action, Escape returns to menu.

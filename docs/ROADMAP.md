# Development roadmap

- Phase 1: bootable Android app and playable 3D prototype.
- Phase 2: complete ball possession, passing, shooting, tackles, goalkeeper and referee.
- Phase 3: touch controls, camera presets, radar, scoreboard and match presentation.
- Phase 4: tactics board, roles, substitutions and set pieces.
- Phase 5: offline career, club facilities, transfer market, training and daily challenges.
- Phase 6: original animation/audio pipeline, accessibility, localization and optimization.
- Phase 7: optional online PvP, clans, events and cloud saves.
